Architecture Extensible

Spécification d'Action (pour Développeur ou IA)

Le moteur du jeu utilise un registre centralisé registerGooseAction(actionObject) en JavaScript (ES6). Vous pouvez copier le contrat ci-dessous pour demander à un développeur ou à une IA de créer de nouvelles actions, puis les coller directement dans l'éditeur ci-dessous. 

/**
 * FORMAT STANDARD D'UNE ACTION — JEU DE L'OIE (JavaScript ES6)
 * Fonction d'enregistrement : registerGooseAction(actionSpec)
 */
{
  id: "identifiant_unique_snake_case", // (String) Identifiant unique de l'action
  name: "Nom court",                   // (String) Affiché sur la case et les cartes (max 18 car.)
  description: "Explication...",       // (String) Texte explicatif affiché au joueur
  icon: "🚀",                          // (String) Emoji ou icône court
  theme: "green",                      // (String) 'green' | 'blue' | 'yellow' | 'purple' | 'red'
  defaultWeight: 15,                   // (Number) Poids relatif par défaut (1 à 100)
  canBeOnBoard: true,                  // (Boolean) Peut être placée sur une case du plateau
  canBeChanceCard: true,               // (Boolean) Peut être tirée comme Carte Chance
  canBePlayerCard: true,               // (Boolean) Peut être reçue en main comme Carte Action

  /**
   * Fonction pure d'exécution de l'action
   * @param {Object} gameState - État complet du jeu (modifiable directement, déjà cloné) :
   *   - gameState.players : Array<{ id, name, color, position (1..63), skipTurns, hand: Array<actionId> }>
   *   - gameState.board   : Array<{ number (1..63), actionId: String|null }>
   *   - gameState.turnIndex : Index du joueur courant dans gameState.players
   *   - gameState.round   : Numéro de la manche
   *   - gameState.maxCell : 63
   * @param {String} playerId - Identifiant du joueur qui déclenche l'action (ex: "p1")
   * @param {Object} context  - { source: 'CELL'|'CHANCE_CARD'|'PLAYER_CARD', cellNumber: Number, lastRoll: Number }
   * @returns {Object} {
   *   gameState: Object,          // Nouvel état du jeu mis à jour
   *   message: String,            // Message narratif affiché dans le journal
   *   extraTurn: Boolean,         // true si le joueur gagne le droit de relancer immédiatement
   *   triggerChanceCard: Boolean  // true si l'action force le tirage d'une Carte Chance
   * }
   */
  execute: function(gameState, playerId, context) {
    const player = gameState.players.find(p => p.id === playerId);
    // Exemple : Avancer de 4 cases sans dépasser 63
    player.position = Math.min(gameState.maxCell, player.position + 4);
    return {
      gameState: gameState,
      message: `${player.name} profite d'un raccourci et avance à la case ${player.position} !`,
      extraTurn: false,
      triggerChanceCard: false
    };
  }
}

Comment jouer ?

1. Objectif : Soyez le premier joueur à atteindre exactement la case 63 au cœur du Jardin des Oies. Si votre lancer dépasse 63, vous reculez du nombre de cases en trop !

2. Plateau dynamique : À chaque début de partie, les actions sont distribuées aléatoirement sur les cases selon la probabilité de couverture et le poids de chaque action (configurables dans Paramètres & Probabilités).

3. Cartes Chance : Certaines cases déclenchent le tirage d'une Carte Chance dont l'effet s'applique immédiatement.

4. Cartes Action en main : De temps en temps à la fin d'un tour, vous recevez aléatoirement une Carte Action dans votre main (jusqu'à 3 cartes). Vous pouvez l'activer pendant votre tour avant de lancer les dés !
